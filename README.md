# 🏥 Plateforme de Gestion Médicale (Santée)

## 📝 Description
Une application web complète conçue pour simplifier la gestion hospitalière. Elle permet de gérer les dossiers patients, les rendez-vous des docteurs et d'assurer le suivi médical de manière sécurisée.

## ✨ Fonctionnalités Principales
*   **Gestion des Patients :** Création et suivi des dossiers médicaux numériques.
*   **Planning des Docteurs :** Gestion des rendez-vous et disponibilités.
*   **Sécurité :** Système de connexion sécurisé et protection des données sensibles.
*   **Tableau de Bord :** Vue d'ensemble de l'activité hospitalière.

## 🛠️ Stack Technique
*   **Langage :** PHP 8+
*   **Base de données :** MySQL
*   **Frontend :** HTML, CSS, JavaScript
*   **Bibliothèques tierces :** PHPMailer (pour l'envoi d'emails)
